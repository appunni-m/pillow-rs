# Contributor Covenant Code of Conduct

Contributors are expected to be respectful, specific, and constructive. Do
not harass people, publish private information, or use project spaces for
discrimination, threats, or sexualized conduct. Keep technical disagreement
focused on the code, evidence, and user impact.

Report conduct concerns privately through the [GitHub security advisory
channel](https://github.com/appunni-m/pillow-rs/security/advisories/new) when
the report contains sensitive information. For a non-sensitive concern, open
an issue and request private contact. Maintainers may edit, close, or remove
content and may restrict participation when needed to keep the project safe.
