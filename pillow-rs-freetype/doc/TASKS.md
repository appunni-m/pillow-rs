## Remaining: 312 FT failures

All 312 FT failures are getmask SHA mismatches. No bbox or structural errors. These are **subpixel anti-aliasing differences** between our Rust autohinter port and C's autohinter. Cause: 1-unit rounding differences accumulate through the pipeline.

### Pipeline stages that can contribute 1-unit errors

## Path to 100% FT pass rate

### Approach: Systematic per-function C-vs-Rust tracing

For each pipeline stage, dump intermediate values from both C and Rust for a single failing glyph. Find the first point of divergence, fix it, re-test.

C tracing infrastructure:
- `/tmp/gen_ft_refs` — compiled FreeType 2.14.3 binary from vendored source
- Need: `trace_edges` binary that dumps internal autohinter state
- Alternative: Add `FT_TRACE` level 7 output by building FreeType with `-DFT_DEBUG_LEVEL_TRACE`

### Task breakdown

**T9: Add FT_TRACE instrumentation to gen_ft_refs**  
Rebuild FreeType with `-DFT_DEBUG_LEVEL_TRACE`, add debug hooks to dump:
- After compute_segments: segment positions, directions, heights
- After compute_edges: edge fpos, opos, pos, flags
- After hint_edges: adjusted edge positions
- After align_strong_points: touched point positions
- After IUP: all point positions
→ Compare with our code's output for same glyph → find first divergence

**T10: Fix first divergence**  
Apply the fix identified in T9. Run tests, measure delta.

**T11: Repeat T9-T10 for remaining divergence points**  
After each fix, re-run coverage matrix. Expected: 1-5 fixes needed, each recovering 50-100+ tests.

**T12: Implement native TrueType hinting for PIL parity**  
Parse fpgm/prep/cvt tables, implement instruction interpreter. Large scope — 2000+ lines.
