# Code of Conduct

This project follows the Rust community norms: be respectful, technical, and
specific. Discuss code and evidence, not people.

## Expected Behavior

- Keep reviews factual and actionable.
- Assume contributors are trying to improve the project.
- Explain tradeoffs with concrete references to code, tests, or docs.
- Respect the pure-Rust, no-runtime-FFI parity goal.

## Unacceptable Behavior

- Harassment, insults, or discriminatory language.
- Publicly sharing private security reports before maintainers can respond.
- Weakening tests, fixtures, or thresholds to claim progress.

## Enforcement

Maintainers may edit or remove comments, close discussions, or block
participation when behavior harms the project or contributors.
