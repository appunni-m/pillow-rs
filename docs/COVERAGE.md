# pillow-rs coverage evidence

This page is the landing page for the active manifest-driven coverage system.
The previous mode-by-operation matrix was generated by a retired fixture
harness and is no longer a current coverage report.

## Current sources

- Contract and selectors:
  [`pillow-rs/tests/fixtures/manifest.yaml`](../pillow-rs/tests/fixtures/manifest.yaml)
  and `pillow-rs/tests/fixtures/inputs/coverage/`.
- Target evidence: `build/migration-parity/coverage-result-rust.json` and its
  source-bound LCOV/context receipts.
- Generated summaries:
  [`docs/generated/migration-coverage-status.md`](generated/migration-coverage-status.md)
  and [`docs/generated/migration-parity-status.md`](generated/migration-parity-status.md).
- Reverse Pillow source coverage:
  `build/migration-parity/pillow-oracle-coverage-result.json` and the ordered
  [`coverage-pillow-missing-feature-manifest.md`](coverage-pillow-missing-feature-manifest.md).

Run the maintained coverage flow with:

```sh
make migration-parity-inputs-check
make migration-parity-coverage
make migration-parity-pillow-coverage
make migration-parity-pillow-missing-manifest
make migration-parity-docs
```

Coverage counts are meaningful only with the manifest hash, selected input IDs,
backend, source revision, and execution status. A mapped case that did not
execute is `not_proven`; it is not silently counted as covered. WGSL source
lines remain unmeasured until shader instrumentation is available.

The latest integrated parity/coverage counts and backend classification are
maintained in
[`docs/benchmark-backend-pending-2026-09-03.md`](benchmark-backend-pending-2026-09-03.md).
