## Why no batch was added

There are valid future candidates, but adding them would require editing the
shared parity inputs/generator and then running managed CPU parity to prove a
coverage delta. The audit explicitly prohibited those fixture edits, and the
checkpoint prohibited broad execution. The evidence supports a small future
batch, not a code change or a justified claim of improved coverage in this
commit.

The highest-value follow-up order is:

1. Run the existing `identity-mesh` and Mandelbrot cases through the managed
   CPU lane to resolve the current zero-hit dispatch evidence.
2. Add the single I;16L RGBA-mask paste case.
3. Add the three projective boundary cases, then the L/LA/RGBA projective mode
   matrix if the first run confirms dispatch.
4. Add the Color3DLUT clamp case and mesh outside-source case only if their
   oracle inputs are accepted and the managed report shows a delta.
