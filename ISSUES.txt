=== TEST-DRIVEN BENCHMARK APPROACH ===
Every test creates IDENTICAL inputs for PIL and RSPIL, runs the SAME
operation, and asserts pixel-exact output. This PROVES the operation
produces correct output. The benchmark MUST use the same parameters.

Pattern from test_image_resize.py:
  pil = PIL.Image.new("RGB", (100,100), (255,128,64))
  rs  = Image.new("RGB", (100,100), (255,128,64))
  pil_r = pil.resize((50,50), PIL.Image.BILINEAR)
  rs_r  = rs.resize((50,50), Resampling.BILINEAR)
  assert_images_equal(rs_r, pil_r)  # VERIFIED identical

For benchmarks: use same op params, scale image to 2048x1536 for timing.
If test passes but benchmark hash mismatches → scaling broke something.
